Nome do site: SafeWeb

Objetivo:
Conscientizar usuários sobre golpes digitais e apresentar formas de prevenção e segurança na internet.

Público-alvo:
Usuários de internet, principalmente jovens e adultos.

IA utilizada:
ChatGPT, como apoio no desenvolvimento do código, interface e organização do projeto.

Tecnologias utilizadas:
HTML5, CSS3, JavaScript, Git e GitHub.

Modelo:
SPA (Single Page Application), com alteração dinâmica do conteúdo sem recarregar páginas diferentes.

GitHub:
https://github.com/pedrohenriqsm/SafeWeb
